# Learning workspace

- `units/` stores one learning board per same-ID Markdown and JSON pair.
- Markdown contains the board title and description; JSON contains source metadata, tags, visual blocks, timestamps, and provenance.
- Keep block IDs stable. Preserve each block's cognitive level and source locator.
- Generated explanations use `author: "model:<provider>"`; user-written boards use `author: "user"`.
- Edit through Thinking OS when possible so snapshot synchronization preserves the complete collection.
